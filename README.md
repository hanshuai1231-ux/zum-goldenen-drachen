# Zum Goldenen Drachen – Website v2

Complete static website for China Restaurant Zum Goldenen Drachen, Hauptplatz 5, 3250 Wieselburg.

## Included
- Real restaurant and food photos supplied by the owner
- Prominent Mittagsbuffet / All You Can Eat section
- Food showcase
- Restaurant interior gallery
- Contact and Google Maps route link
- Existing online ordering link
- Responsive mobile layout

## Deploy
1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Add `zumgoldenendrachen.at` and `www.zumgoldenendrachen.at` in Vercel Domains.
4. In easyname, add the DNS records Vercel gives you.

Before public launch, add Impressum and Datenschutz pages appropriate for the Austrian business.
